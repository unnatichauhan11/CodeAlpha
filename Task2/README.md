# CodeAlpha Task 2: Calculator

A browser-based calculator built with HTML, CSS, and vanilla JavaScript.

## Features

- Addition, subtraction, multiplication, and division
- Decimal number input and chained calculations
- Repeated equals operations
- Keyboard input, including Backspace to edit the current number
- Clear with the on-screen button or Escape
- Divide-by-zero handling

## Run

Open `index.html` in a web browser.

## Project files

- `index.html` - calculator markup
- `style.css` - calculator layout and styles
- `script.js` - calculator logic and keyboard controls
